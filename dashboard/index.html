SCADA telemetry reaches HiveMQ with less noise and a verifiable trail.

What this pipeline proves

A Sparkplug B reading enters through authenticated MQTT. Expanso Edge decodes the protobuf payload, rejects invalid readings, removes low-value changes with state kept at the edge, re-encodes the result, and sends three purpose-built outputs to HiveMQ over authenticated TLS.

The explorer below uses records from the repository fixture. Its YAML excerpts are loaded from the shipped pipeline file, so the page cannot drift into a second version of the implementation.

Local proof Expanso Edge local mode, source broker, and secured HiveMQ
Cloud path The same job is deployed by Expanso Cloud to labeled edge nodes
Wire format Eclipse Tahu Sparkplug B protobuf before and after processing

The data stays on the data plane

Expanso Cloud manages the job. Telemetry moves directly from the source through the edge node to HiveMQ.
